# Changelog

## 0.1.0

Initial release.

LunarKit provides a framework-independent browser terminal with native text editing, command history, completion, cancellable commands, interactive input, choices, and restorable conversation views.

The package includes core, Markdown, charts, models, and Streamline icon entries with TypeScript declarations. Styles and optional self-hosted fonts are imported separately. Host controls include focus, scrolling, scene transitions, messages, command notifications, cleanup stacks, batched output, and incremental text output.

Markdown uses DOMPurify with a DocumentFragment for Trusted Types compatibility. Scrolling preserves the reading position of oversized panels and responds to user scrolling during programmatic updates.

A Vite TypeScript starter and four examples demonstrate terminal pages, text files, a service workspace, and interactive storytelling. Original code is MIT licensed; bundled fonts and icons retain their respective licenses.
