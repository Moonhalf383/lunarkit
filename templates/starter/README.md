# LunarKit starter

Copy this directory into a new project, then install dependencies and start Vite:

```sh
npm install
npm run dev
```

Run `npm run build` to type-check and build the production site.

The `help` command lists available actions. `story` combines a scene transition, skippable text, and a choice. `load` uses AbortSignal to cancel a request and updates an existing text output. A cleanup stack destroys the terminal on page exit and Vite hot replacement.

Add `lunarkit/fonts/noto-sans-sc.css` for the bundled Chinese font. Applications using `lunarkit/icons/streamline` must provide Streamline attribution and a CC BY 4.0 link in their About or Credits section and retain the bundled license. This starter uses text output and fonts.
